Owner sign-in

Paste an owner API key. It is kept only in this tab's session storage — never in a cookie, localStorage, or a URL — and is cleared when you sign out or close the tab.

Agent sign-in

For agents owned by the fleet owner, via AgentID (standard OpenID Connect with PKCE — no secret). Agent sessions are read-only: pairing approvals and action-approval decisions stay human-only.

AgentID is not configured for this dashboard yet — see the README's AgentID section.

Signed in as agent

Agent sessions are read-only by policy. Fleet API access for agents unlocks when the control plane ships session exchange (POST /v1/agent/exchange); until then this session proves identity only — it is never sent to the plane.
