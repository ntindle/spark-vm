# playwright_wheel_hashes.txt — SHA-256 pinned wheel downloads for the
# toolset updater's playwright layer (issue #532).
#
# Format: one `<sha256>  <url>` line per pinned artifact. Blank lines and
# `#` comments are ignored. The updater (`deploy/toolset-update.sh`,
# `_playwright_layer`) looks up the line whose URL basename is exactly the
# wheel asset for the pinned version + box arch, downloads it, and refuses
# unless the downloaded bytes match the listed digest.
#
# Hash authority: the hashes are recorded here at commit time from PyPI's
# JSON API (https://pypi.org/pypi/playwright/<version>/json); the installed
# copy (see `toolset-update.sh install`, which copies this file into the
# state dir next to self_update_pins.conf) is the runtime authority. The
# update plane never reads this file from the live checkout.
#
# Discipline: bump this file in the same PR that bumps the playwright pin
# in scripts/self_update_pins.conf. The test suite pins the sync
# (test_playwright_wheel_hashes_cover_pins_conf). Only the linux wheels
# are listed — spark-vm boxes are linux.
#
# playwright = 1.62.0
